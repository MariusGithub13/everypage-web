EveryPage

Ask a PDF a question. It names the page, proves each quote is really there, and tells you when a page could not be read instead of telling you "no".

1Choose a document

Try an invented sample, or use your own PDF.

Works on English PDFs, scanned or not; scans also in Romanian, German, French, Spanish, Italian.





2What was actually read:

Before any question, every page is read and measured. A scan is not an empty page, and a page read sideways is noise that looks like text.

3Ask

Three verdicts, never two

FOUNDThe answer, with quotes. Code checks each quote is literally on the page it names. A quote that is not there is thrown away.
NOT FOUNDAllowed only when every page was read and every page was examined. Then it is a real negative.
CANNOT SAYNothing was found, but some page could not be read. That is not a "no", and the tool says which pages.

The model never gets to say "it is not in the document". Only the code says it, from the page count. Each page is examined by an NVIDIA Nemotron model served by Nebius Token Factory. Uploaded files are deleted after 30 minutes and are not used for anything else. This is a reading aid, not legal advice: read the quote.
